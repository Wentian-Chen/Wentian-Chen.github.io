    SimPickGen

    项目简介

    SimPickGen（Simulator-based Pick-and-Place Generation）是一个基于 IsaacSim 的全自动机械臂随机位姿抓取及数据采集系统。

    在具身智能领域，视觉-语言-动作模型（VLA）的训练高度依赖高质量、大规模的 抓取演示数据。然而，现实世界的数据往往稀缺且昂贵：实机采集需要部署整条 硬件链路、逐条录制遥操作或示教轨迹，人力与时间成本高昂，且难以快速扩充 数据规模。

    SimPickGen 的出发点正是为了解决这一问题——在仿真环境中自动生成大规模的 机械臂随机位姿抓取任务，并同步完成数据的采集、保存与导出，为 VLA 模型 的训练提供稳定、可扩展的数据来源。

    项目定位

    SimPickGen 定位于"数据生产基础设施"：它本身不是模型，也不是单一的任务 演示，而是一套面向数据规模需求的自动化生产线。项目将仿真引擎与自动化 调度结合起来，让数据采集从"人工录制的作坊模式"走向"批量生产的流水线 模式"。

    !!! note "说明"

    本项目当前以通用化描述呈现系统设计与工作流程，具体实现细节将随版本
迭代逐步补充。

    项目背景

    数据稀缺：VLA 训练的瓶颈

    VLA 模型需要从海量"观测-指令-动作"三元组中学习视觉与动作之间的映射关系。 理论上，数据量越大、多样性越丰富，模型的泛化能力就越强。但在实际研发中， 绝大多数团队都面临数据获取渠道有限的问题：

    • 公开数据集与自身任务场景存在偏差，直接使用效果不佳；
    • 自建数据集需要投入大量资源，短期内难以形成规模；
    • 数据的质量与多样性难以同时保证，常常需要大量的人工筛选与清洗。

    实机采集：昂贵且低效

    真实机器人上的数据采集通常依赖人工遥操作、示教或动捕等方式，每条高质量 演示数据背后都对应着操作人员的长时间投入。此外，实机采集还受限于硬件 数量、场地空间与安全性等因素：

    • 单条数据的采集周期长，难以通过堆人力线性扩张；
    • 场景布置与物体摆放难以在短时间内大量变化，数据多样性受限；
    • 长时运行会带来设备磨损与安全隐患，进一步推高采集成本；
    • 复杂技能（如精细抓取、长程操作）的示教门槛高，成功率不稳定。

    仿真采集：规模化数据的可行路径

    与实机采集相比，仿真环境具备完全可控的物理参数、场景配置与资产布局， 可以在短时间内批量生成大量具有随机性的抓取任务。利用仿真域随机化 （Domain Randomization）等技术，还能显著提升数据的多样性，帮助模型在 迁移到真实场景时保持鲁棒性。

    仿真与实机采集的核心差异可以概括如下：

    维度 仿真采集 实机采集
    采集速度 高，可并行、批量运行 低，逐条录制
    人力成本 低，全自动运行 高，依赖操作人员
    数据多样性 高，位姿与场景可随机化 受场地与布置限制
    物理真实性 依赖仿真精度 完全真实
    安全风险 无硬件磨损风险 存在设备与人身风险

    仿真采集并非要完全替代实机采集，而是作为规模化数据生产的关键补充。 SimPickGen 正是基于这一思路构建的。

    系统设计

    SimPickGen 的整体工作流程分为五个阶段：环境搭建 → 场景与资产构建 → 随机位姿生成与抓取 → 数据采集与保存 → 数据后处理与导出。

    环境搭建 → 场景与资产构建 → 随机位姿生成与抓取 → 数据采集与保存 → 数据后处理与导出

    整个流程以"自动化"和"批量化"为核心诉求：前两个阶段负责搭建生产环境， 中间两个阶段负责生产原始数据，最后一个阶段负责将原始数据加工为可直接 训练的标准格式。五个阶段首尾衔接，构成一条完整的数据流水线。

│ 环境搭建    │──▶│ 场景与资产  │──▶│ 随机位姿生成  │──▶│ 数据采集与保存 │──▶│ 数据后处理导出 │
│            │   │ 构建       │   │ 与抓取       │   │              │   │              │
└────────────┘   └────────────┘   └──────────────┘   └──────────────┘   └──────────────┘

    环境搭建

    系统基于 IsaacSim 仿真平台搭建，完成仿真环境的基础配置，包括物理引擎参数、 渲染设置以及各类扩展模块的加载，为后续的仿真实验提供稳定的运行环境。 环境搭建是整个系统的地基，直接影响物理仿真精度与渲染质量。

    场景与资产构建

    构建抓取实验所需的仿真场景，包括机械臂模型、桌面平台以及被抓取的物体 资产。场景中的物体种类、尺寸与纹理可以根据训练需求灵活配置，为数据 多样性提供基础保障。场景的搭建遵循模块化思路，支持快速替换与组合， 便于扩充新的物体类别。

    随机位姿生成与抓取

    系统在场景中随机生成物体的初始位姿（位置与朝向），驱动机械臂完成规划、 移动与抓取动作。每一次抓取尝试的位姿组合都是随机产生的，从而保证生成 数据的多样性，覆盖训练所需的广泛分布。对于抓取失败的尝试，系统会记录 失败信息并自动进入下一轮，不影响整体流程的自动化运行。

    数据采集与保存

    在机械臂执行抓取任务的过程中，系统同步记录仿真观测数据，包括视觉图像、 机械臂关节状态、末端执行器位姿以及任务相关的动作指令等信息，并按照 统一的格式组织与保存，形成可供训练使用的原始数据集。采集过程与任务 执行同步进行，保证数据与动作的时序对齐。

    数据后处理与导出

    原始数据经过清洗、对齐与格式化等后处理步骤，导出为符合主流训练框架 要求的数据格式，可以直接用于 VLA 模型的训练，也可以进一步与真实采集 数据混合使用。后处理环节保证了数据质量的统一，降低了下游使用门槛。

    !!! tip "技巧"

    建议在数据导出阶段同时保留原始仿真配置（场景布局、位姿分布参数等）
的元信息，便于后续复现与排查数据质量问题。

    技术亮点

    SimPickGen 的价值体现在自动化程度、数据多样性与产线效率三个方面，核心 亮点如下。

    全自动化

    从场景构建、位姿生成到抓取执行、数据保存，整条链路无需人工干预，可以 长时间批量运行，大幅降低数据采集的人力成本。系统只需一次性配置，即可 在无人值守的情况下持续产出数据。

    仿真域随机化

    通过随机化物体位姿、场景布置等因素，提升数据的多样性，增强模型在真实 环境中的泛化能力。随机化范围覆盖物体位置、朝向、类别与纹理等多个维度， 让模型在训练阶段就能接触丰富的分布变化。

    批量数据生成

    以低成本、高效率的方式规模化产出训练数据，为 VLA 模型的迭代提供持续、 稳定的数据供给。相比实机采集，仿真采集在相同时间内可以产出数量级更高 的数据。

    数据格式统一

    采集、保存与导出流程一体化，产出的数据可直接用于下游模型训练，减少 中间转换的额外开销。统一的数据规范也便于与真实采集数据混合使用，灵活 构建混合训练集。

    未来展望

    数据集发布

    计划将系统生成的仿真数据集整理并公开，供具身智能社区研究与训练使用， 推动开源生态中仿真数据资源的共享与复用。

    多臂与移动操作

    将系统从单臂桌面抓取拓展到双臂协同抓取以及移动操作等更复杂的任务场景， 覆盖更广泛的操作形态，适配更多真实应用需求。

    任务多样性

    在抓取的基础上加入放置、堆叠、整理等更多任务类型，进一步提升数据集 的覆盖面，为 VLA 模型提供更丰富的任务信号。

    总结

    SimPickGen 将仿真环境与自动化流水线结合，以极低的成本规模化产出高多样 性的机械臂抓取数据，直接服务于 VLA 模型的数据需求。对于个人开发者与 小团队而言，它把数据采集的门槛从"购买硬件、安排人手"降低到"配置一次 仿真任务"，让数据驱动的具身智能研究变得更加可及。

    未来，随着数据集的发布与任务形态的拓展，这套系统有望成为具身智能数据 基础设施建设中重要的一环。欢迎对仿真数据生产感兴趣的开发者关注并参与 交流。
